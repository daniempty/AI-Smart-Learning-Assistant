ZOI Nails & Beauty website

Open index.html in a browser to view the site.
To put it online, upload the whole folder (keep the css, js and assets folders next to index.html) to Netlify, GitHub Pages or any web host.

Edit products and prices: js/app.js (the list "P" near the top).
Add a product photo: put the image in assets/ and add img:"assets/yourfile.jpg" to that product.
Change colours and fonts: css/style.css
WhatsApp number: js/app.js (search for 923239051866)
